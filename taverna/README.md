# Welcome to Loco :train:

[Loco](https://loco.rs) is a web and API framework running on Rust.

This is the **SaaS starter** which includes a `User` model and authentication based on JWT.
It also include configuration sections that help you pick either a frontend or a server-side template set up for your fullstack server.


## Prerequisites

This project requires PostgreSQL with the following extensions:
- `uuid-ossp`
- `ltree`
- `pgmq`

**Note on `pgmq`:** The `pgmq` extension must be installed separately on your PostgreSQL server before running migrations, as it typically requires superuser privileges. It is not automatically installed by the migrations.
